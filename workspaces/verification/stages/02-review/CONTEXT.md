# verification / 02-review: Verifier review

## Input
Evidence records

## Process
Follow rules/ENGINEERING.md. Work in small steps. Write the failing test or vector first, then the change.
Record any real decision in docs/DECISIONS.md.

## Output
An accepted or rejected decision with a reason

## Completion
A named verifier decided and the decision is published.

## Do not
Never let software accept evidence on its own.
