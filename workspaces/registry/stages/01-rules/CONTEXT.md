# registry / 01-rules: Write or change a rule

## Input
A proposed rule and why

## Process
Follow rules/ENGINEERING.md. Work in small steps. Write the failing test or vector first, then the change.
Record any real decision in docs/DECISIONS.md.

## Output
A vector in conformance/registry_vectors.json that fails first

## Completion
The vector exists and fails, then the model passes it.

## Do not
Never change a rule without a vector and a decision entry.
