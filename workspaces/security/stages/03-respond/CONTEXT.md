# security / 03-respond: Respond to an incident

## Input
An alert or a report

## Process
Follow rules/ENGINEERING.md. Work in small steps. Write the failing test or vector first, then the change.
Record any real decision in docs/DECISIONS.md.

## Output
A suspension if needed, a fix, a changelog line and a new test

## Completion
The failure is now impossible or loudly detected.

## Do not
Never delete evidence. Suspend, then investigate.
