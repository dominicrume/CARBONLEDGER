# estimator / 03-review: Let a person overrule a category

## Input
A tier-4 estimate and the product's text

## Process
Follow rules/ENGINEERING.md. Work in small steps. Write the failing test or vector first, then the change.
Record any real decision in docs/DECISIONS.md.

## Output
The same estimate with a person's chosen category, noted on the receipt

## Completion
The receipt says a person chose the category.

## Do not
Never hide that an estimate is an educated guess.
